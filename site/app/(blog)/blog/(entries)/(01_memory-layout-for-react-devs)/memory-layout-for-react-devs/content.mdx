</ArticleHeading>

<Typography variant="articleBody">
  Many values prefer addresses divisible by a particular number. A{' '}
  <Typography
    as="code"
    variant="articleCode"
  >
    u32
  </Typography>
  , for example, typically wants a four-byte boundary. When fields do not line
  up, the compiler may insert unused bytes called **padding**.
</Typography>

<Typography variant="articleBody">
  This is not waste caused by a lazy compiler. Alignment lets the machine read
  values efficiently and, on some architectures, safely. Rearranging fields can
  sometimes reduce padding—but doing so blindly can make an API worse to save a
  handful of bytes.
</Typography>
